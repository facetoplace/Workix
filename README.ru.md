# Workix

**Языки:** [English](README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Türkçe](README.tr.md) · [Українська](README.uk.md) · [हिन्दी](README.hi.md) · [中文](README.zh.md)

Workix — это место, где люди, проекты и работа находят друг друга.

[Хаб Workix](https://workix.co) объединяет в одном каталоге три направления:

- **Проекты** — стартапы, продукты и сообщества, которые ищут людей.
- **Роли и заказы** — открытые предложения работы с описанием, бюджетом, тегами и способом откликнуться.
- **Участники** — специалисты, соавторы и менторы, которые могут находить друг друга по навыкам и интересам.

Workix — не традиционная фриланс-биржа. Он не пытается заменить отношения между проектом и специалистом. Объявление ведёт к предпочтительному для владельца проекта способу связи или форме отклика, а Workix помогает легко публиковать, находить и распространять такие возможности.

Люди могут просматривать каталог в интернете. ИИ-агенты могут искать в нём и управлять объявлениями через MCP или REST API. Тот же локальный MCP позволяет собирать предложения с внешних платформ, при этом учётные данные от платформ остаются на компьютере пользователя.

**Открыть Workix:** [workix.co](https://workix.co)  
**Руководство для агентов:** [workix.co/agent](https://workix.co/agent)  
**Справочник API:** [workix.co/api.txt](https://workix.co/api.txt)

## Что находится в этом репозитории?

В этом репозитории находятся открытые клиенты и интеграции Workix. Они используют API центрального хаба по адресу `https://workix.co`, поэтому локальная копия может отображать общий каталог без необходимости поддерживать отдельный каталог.

- В [`views/`](views/) находятся страницы витрины.
- В [`assets/`](assets/) находятся браузерное приложение, стили, переводы, файлы PWA и общедоступная документация API.
- В [`mcp/`](mcp/) находятся MCP-сервер на TypeScript, инструменты Workix и адаптеры для поддерживаемых платформ с вакансиями и заказами.
- В [`docker/`](docker/) находится небольшой образ nginx для размещения витрины.
- В [`docs/`](docs/) находятся общедоступные руководства для агентов и самостоятельного размещения.

Две основные части независимы друг от друга:

1. **Витрина** — веб-интерфейс для просмотра каталога Workix. Им можно пользоваться на [workix.co](https://workix.co) или разместить UI на собственном домене.
2. **MCP-сервер** — инструменты, с помощью которых ИИ-агент может искать в Workix, управлять вашими объявлениями и профилем, готовить предложения и работать с поддерживаемыми внешними источниками.

Данные каталога предоставляет центральный API Workix. Для запуска витрины или подключения MCP-клиента не нужны рабочие секреты.

## Использование Workix с ИИ-агентом

С `WORKIX_API=https://workix.co` агент может искать проекты, роли, заказы, участников и менторов. С `WORKIX_AGENT_KEY` он также может создавать и обновлять объявления и управлять профилем участника.

**Рекомендуем** ставить MCP из исходников этого репозитория (самая свежая сборка). `npx`/`npm` — опционально и могут отставать от git.

Требуется **Node 22.5 или новее**: локальное хранилище — SQLite через встроенный в Node модуль `node:sqlite`, поэтому при установке ничего не компилируется.

```bash
git clone https://github.com/facetoplace/Workix.git
cd Workix/mcp
npm install
npm run build
```

Пример конфигурации MCP для Cursor (из исходников):

```json
{
  "mcpServers": {
    "workix": {
      "command": "node",
      "args": ["FULL/PATH/TO/Workix/mcp/dist/index.js"],
      "env": {
        "WORKIX_API": "https://workix.co",
        "WORKIX_AGENT_KEY": "wix_…"
      }
    }
  }
}
```

Опционально: `npx -y @workix/mcp`. Зарегистрируйтесь на [workix.co](https://workix.co), чтобы получить ключ агента. Для общедоступного поиска ключ не обязателен, но он необходим для действий, связанных с вашей учётной записью.

Учётные данные внешних платформ должны храниться только в локальном окружении MCP. Не отправляйте в хаб Workix пароли и токены от Upwork, Kwork или других платформ.

Инструкции по установке, список доступных инструментов и настройки отдельных источников приведены в [`mcp/README.md`](mcp/README.md).

### Главное в MCP 1.2.2

- В профиле участника можно сохранить интерес к нетворкингу, сотрудничеству и менторству через форматы (`networking`, `startups`, `opensource`, `equity`) со значениями `yes`, `unknown` или `no`, а также свободную заметку.
- `workix_list_performers` умеет находить участников, которые явно выбрали нетворкинг, сотрудничество или менторство; `hidden: true` убирает профиль из публичных лент и поиска.
- `workix_bump_profile` поднимает профиль наверх без редактирования. Хаб разрешает один bump раз в 3 дня и сообщает время следующей попытки.
- В MCP также входят возможности 1.2.0: раздельные collect/search, новые источники и браузерные адаптеры с сохранённой сессией. Подробности — в [`mcp/CHANGELOG.md`](mcp/CHANGELOG.md).

## Размещение витрины на своём домене

Проекты и сообщества могут разместить UI Workix на домене наподобие `work.example.com`. Такое зеркало продолжит получать общий каталог с `https://workix.co`.

1. Разверните `views/` и `assets/` или воспользуйтесь образом из [`docker/`](docker/).
2. Укажите для UI адрес хаба:

   ```html
   <meta name="workix-api" content="https://workix.co" />
   ```

   Также можно задать для `API_BASE` или `WORKIX_API` значение `https://workix.co`.
3. Настройте DNS и хостинг для выбранного домена.

Объявления, связанные с этим доменом, могут отображаться приоритетно для посетителей зеркала. Рабочий пример доступен на [work.facetoplace.app](https://work.facetoplace.app/), а подробности — в [`docs/self-host.md`](docs/self-host.md).

## Использование других платформ через Workix MCP

Workix MCP также служит единым интерфейсом для работы с внешними фриланс-биржами и сайтами вакансий. Агент может искать сразу в нескольких источниках и собирать результаты в один дайджест, открывать конкретное объявление, составлять предложение, а затем либо отправлять его через доступный API, либо готовить для вас пошаговый список действий в браузере.

Эти интеграции работают локально. API-токены, логины платформ и браузерные сессии остаются на вашем компьютере и не отправляются в хаб Workix. Для отправки предложения всегда требуется явное подтверждение человека.

### Готовность платформ

Оценка показывает, насколько на сегодняшний день готов **предполагаемый рабочий процесс Workix**, а не степень охвата возможностей самой платформы:

- **5/5** — поиск и отправка предложения работают через поддерживаемый API.
- **4/5** — надёжный поиск; у отправки предложения или аутентификации всё ещё есть резервный вариант либо ограничение.
- **3/5** — полезная интеграция, но учётные данные, прокси или неофициальный интерфейс влияют на надёжность.
- **2/5** — источник для отслеживания с помощью браузера, а не автоматизированная лента.
- **1/5** — только ссылка или пошаговый список действий; глубокая автоматизация намеренно не поддерживается.

Столбец **Политика автоматизации** намеренно составлен консервативно. Условия платформ и разрешения API могут меняться, поэтому пользователи также должны соблюдать актуальные правила каждого источника и своей учётной записи.

### Об источниках со счётчиком

Все источники выше читаются бесплатно, кроме **JobsPipe**: он списывает один кредит за каждую отданную вакансию. Именно поэтому это единственная площадка, которую обычный дайджест `include_jobs` не трогает — иначе плановый запуск мог бы незаметно израсходовать месячную квоту. Обращайтесь к нему осознанно: инструментом `workix_jobspipe_search`, явным `platforms: ["jobspipe"]` или включив `JOBSPIPE_IN_DIGEST=1`. Локальный счётчик отслеживает расход этого MCP и не даёт начать запрос, когда заданный месячный бюджет исчерпан; остаток показывает `workix_jobspipe_usage`.

JobsPipe работает только на чтение. Он индексирует чужие доски и не имеет эндпоинта для публикации, поэтому разместить вакансию через него нельзя — объявление попадёт в этот индекс, только если будет опубликовано в источнике, который он уже обходит.

### О мосте JobSpy

Indeed, Glassdoor, ZipRecruiter, Naukri и BDjobs читаются через [JobSpy](https://github.com/speedyapply/JobSpy) (MIT), который устанавливаете **вы**: `pip install -U python-jobspy`, Python 3.10–3.12. Ничего не произойдёт, пока вы прямо не назовёте одну из этих площадок — обычный дайджест их не трогает.

Мы вызываем его, а не копируем код, намеренно. Эти доски читаются приватными эндпоинтами с учётными данными из их же мобильных приложений; так эти данные остаются в вашей установке, а не распространяются внутри нашего пакета, и авторы скрейперов продолжают их поддерживать.

Учтите: в наших тестах результаты вернул только Indeed. Остальные блокируются или ограничиваются с большинства адресов, а BDjobs сейчас падает с ошибкой внутри самого JobSpy. Заработают ли они у вас — зависит от вашей сети, и решение об их использовании принимаете вы, соблюдая условия каждой доски.

**Охват сегодня:** 64 площадки в каталоге, 36 поставляются загружаемыми модулями-адаптерами. Кроме источников вакансий и фриланса выше, та же система модулей обслуживает каталог приложений **dStore** (опубликовать живой сайт или PWA, найти похожие приложения) и опциональное чтение каналов **Telegram**.

Каталог источников находится в [`mcp/platforms.json`](mcp/platforms.json). Запустите `workix_list_platforms`, чтобы получить список в машиночитаемом формате, и `workix_sources_status`, чтобы узнать, какие интеграции доступны с вашей текущей локальной конфигурацией.

## Участие — помогите расширить базу источников

Workix становится полезнее, когда сообщество подсказывает **новые места, откуда собирать вакансии и заказы**.

**Откройте [Issue](https://github.com/facetoplace/Workix/issues) или PR, если знаете:**

- **сайт / биржу / ленту вакансий** (публичный API, RSS или понятная HTML-лента), которую стоит подключить к MCP-дайджестам;
- **Telegram-канал или чат**, где регулярно публикуют IT/mobile/фриланс/стартап-вакансии (только публичный `@username`).

Достаточно короткой заявки: URL или `t.me/…`, ниша, что посты свежие. Полный адаптер писать не обязательно — предложение уже помогает. Особенно ценны PR с адаптером или добавлением канала в [`mcp/telegram-channels.example.json`](mcp/telegram-channels.example.json).

Также приветствуются: tools MCP, пресеты, тесты, витрина, документация и переводы.
