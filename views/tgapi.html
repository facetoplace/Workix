Данные для Telegram API

Для Telegram-поиска в локальном Workix MCP можно использовать приложение Workix. Пользователю не нужно регистрировать своё приложение.

Сохраните эти строки в `mcp/.env` или в переменные окружения MCP. Имена `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` тоже поддерживаются.

Что здесь безопасно

Это идентификаторы приложения, а не доступ к Telegram-аккаунту. Они сами по себе не дают войти в аккаунт. Для входа TDLib запросит номер телефона, код Telegram и пароль 2FA, если он включён. Workix MCP работает локально: телефон, коды, пароль и сессия не отправляются на workix.co.

Не отправляйте коды и пароль 2FA в чат с агентом. Вводите их только в локальном терминале входа.

Можно создать свои данные

Если Telegram позволяет зарегистрировать приложение в вашей стране, можно получить собственные `api_id` и `api_hash` на my.telegram.org. Это необязательно: для Workix MCP подходят credentials Workix выше.
